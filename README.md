# MoveBox
基于Flutter的MoveBox的VibeCoding开发

由于市面上的视频盒子资源各种各样，本项目是基于Flutter的MoveBox的VibeCoding的项目开发
功能面向视频，音乐，小说，短剧，短视频，直播等，软件内置node,php,python，目前将进入开发阶段，
支持平台有Windows、Linux、MacOS，iOS，Android，HarmonyOS，后续推出电视版本，由于是内置的开发环境和资源
所以数据会很大，占据空间等，也可以提出不同的建议，后续源码公开，数据开发日志也会上传<br>
本人时间紧迫，没有收集资源的能力，现需各位开发者等以及爱好者等征集各种资源，如视频资源，
音乐资源，书源，直播资源，可提交只Issues
软件内置有danmu_api和drpy_node！
